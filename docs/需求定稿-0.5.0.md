# 0.5.0 需求定稿（2026-10-29）

本文件是本轮 7 项待决策项与 7 项新增需求的**唯一口径来源**，替代
`待决策项-0.4.0.md` 中尚未拍板的部分。实现时以本文件为准，与代码冲突以本文件为准。

拍板结论先列在这里，后面各节只写「怎么做」。

| 争议点 | 结论 |
| --- | --- |
| 语音「上滑」 | 上滑 = 锁定继续录，松手不结束，再点一次才结束 |
| 「已掌握」是否影响掌握度 | 不。只做题目级标记，`MasteryCalculator` 公式一行不改 |
| 陪伴作业的倒计时 | 改为**正计时（番茄钟式）**，记专注时长；提问时暂停，回答完自动恢复 |
| 5 分钟提示 | 提示可以求助：「这题已经 5 分钟了，卡住可以问我」，点击直接开提问 |
| 陪伴在底栏的名字 | 陪伴（两字） |
| 过渡动画不可见 | 时长过短 + 位移仅屏宽 1/18 + 系统动画缩放 0.5 三层削完所致，按第六节重做 |

## 二、语音输入与输入区（P0）

参考图为「左切换键 + 中间大块按住说话 + 右相机/更多」三段式。

布局（打字态与语音态共用一条容器，只换中区）：

    附件条（有图时）
    [ ⌨/🎤 ] [  输入框 或 按住 说话  ] [ 📷 ] [ ⋯ ]

- 左键：语音态与键盘态互切，切换后焦点与草稿都不丢；切到语音态自动收起输入法。
- 中区语音态是一整块可长按区域，文案「按住 说话」，高度 ≥ 48dp。
- 右侧相机图标**常驻**（拍题是最高频动作），更多菜单只放「从相册选」。
- 打字态才出现发送/停止键，语音态不出现发送键。
- 附件条（多页缩略图）保持现有位置，不随状态移动。

手势：

- 按下 → 申请录音权限（首次）→ 开始识别，进入录音态；
- 松手 → 结束本轮，把最终结果写回草稿；
- 上滑超过 24dp → 进入**锁定态**（松手不结束），此时录音态浮层换成「点一下结束」按钮，
  再点才结束；锁定态下上滑无效，避免误触；
- 滑动过程中不打断识别，只是停止监听松手事件。

录音态浮层（简易声纹）：

- 12 根竖条，高度由 `onRmsChanged` 归一化驱动，加 80ms 线性插值，避免跳变；
- 文案显示「松手结束 · 上滑锁定」；
- 不做波形回放、不做音量数字。

引擎：

- 设置 → 教学偏好 → 新增「语音识别引擎」，列出
  `queryIntentServices(ACTION_RECOGNIZE_SPEECH)` 枚举到的引擎（去重按包名）；
- 默认值：优先选声明了离线能力、且非 Google 的引擎；没有则选系统默认；
- API 31+ 额外提供「本机识别（离线）」选项（`createOnDeviceSpeechRecognizer`），
  minSdk 24 下该选项不展示；
- 每次识别按 `EXTRA_PREFER_OFFLINE` 传当前是否离线；联网识别失败
  （`ERROR_NETWORK` / `ERROR_NETWORK_TIMEOUT`）时**自动切到离线引擎重试一次**并提示；
- 同一引擎连续 2 次识别结果为空（`ERROR_NO_MATCH` 或空串），提示一次
  「这个引擎听不太清，可以在设置里换一个」，每次启动最多提示一次，不阻断输入；
- 单轮识别上限 55s，到点自动收尾并保留已识别文本。

## 三、启动页与过渡动画（P0）

启动页：

- 背景固定淡紫（与系统 splash 的 `windowSplashScreenBackground` 同色，消掉黑屏空窗）；
- 「ToTop」五字逐个淡入，每字 70ms，各带 4dp 上移，全程 350ms；
- 全部出现后定格 250ms，再 220ms 淡出到首页；最短展示取 820ms；
- 不做循环、不做缩放、不做粒子。

过渡：

- 二级页进入 260ms（淡入 + 屏宽 1/10 横移 + 0.985→1.0 缩放），退出 200ms；
- 底栏同级切换只淡入（180ms），不做横移——横移会把并列关系说成层级关系；
- 时长按系统动画缩放，但**下限 0.8**：系统设 0.5x 时按 0.8 计，避免动画直接消失；
- 位移与缩放走 `graphicsLayer`，不触发重排；
- 目标页的第一帧必须是「背景 + 标题栏」骨架，数据后到再填，
  否则动画会在空白期跑完（当前「看不见」的主因之一）。

## 四、解题页交互（P1）

### 4.1 已掌握（原「我已理解」）

- 位置：顶栏右侧，与「新建对话」并排的勾选图标；本题答完（已有结构化解答且最后一条
  AI 回复正常结束）才可点，之前置灰。
- 点击：给当前题目写 `selfMasteredAt` → 归档当前会话 → 新建对话 → 顶部一句鼓励语。
- 删除底部「我已理解」条。
- 数据：`question` 表新增 `self_mastered_at`（可空），配迁移与 schema 快照；
  **不写入 `mastery`、不改 `MasteryCalculator`**。首页「已掌握」统计仍按掌握度阈值，
  不受此标记影响。

### 4.2 补拍更新错题

- 触发：会话已有解答后再发图。
- 动作：只重跑阶段 A（识题）与阶段 D（知识点），不重跑 B/C；
- 更新 `question` 的图片列表与 `stemText`；沿用原 `mistakeId`，不新增记录、不加复发计数；
- 知识点变化时同步 `mistake_kpoint`（先删后插，同一事务）；
- 完成后气泡提示「已按新照片更新题目，错题本同步」；失败则显式报错并保留旧题干。

### 4.3 错题本多页与免框选

- 题目图片由「只存第 1 页」扩为页列表，详情页横向翻页展示**全部页**；
- 图片均为拍题阶段裁剪后的成品，详情页不提供重新框选入口；
- 旧记录（单图）按一页兼容，不做数据回填。

## 五、陪伴作业改造（P1）

定位：写作业时随手问 + 专注计时，两者同页。

- 计时：正计时（番茄钟式），本题累计专注秒数；提问时暂停，回答结束自动恢复；
  本轮结束写入 `focus_session`（题数、总秒数、提问次数），学情报告新增「专注时长」一栏。
- 提问：常驻语音/文字入口，单轮轻量调用（不走四阶段，不带拍题上下文），
  回答后抽取受控知识点 ID，写入 `forgotten_kpoint`（kpointId、次数、最近时间）。
- 5 分钟提示：本题累计 ≥ 5 分钟，底部出一条轻提示「这题已经 5 分钟了，卡住可以问我」，
  点击直接开提问；每题只提示一次。
- 易忘点用途：首页「需要多练」并列展示；生成针对性复习资料时作为附加原料，
  资料内单列「易忘点回顾」一节。改提示词需同步升 `prompt_version.json`。
- 底栏：首页 / 拍题 / 陪伴 / 功能中心 四项等宽同级，「权重与拍题相当」指同尺寸，
  不做额外放大。
