# 支付与变现方案（个人开发者视角）

> 核查时间：2026-09-11。政策与费率会变，正式签约前请以各家官网/后台当期数字为准。
> 下文明确标注 **【已核实】**（有一手来源）与 **【待确认】**（需你自行向渠道核实）。

## 0. 结论速览

| 场景 | 推荐做法 |
| --- | --- |
| 免费获点 | 激励视频广告，累计 10 次 = 1 点数（穿山甲 Android/鸿蒙 + AdMob iOS） |
| 增长 | 注册赠 1 点数（够跑通一次完整分析，转化率最高的钩子） |
| Android / 鸿蒙付费 | **无营业执照阶段**：第三方聚合支付（虎皮椒等，2%~2.6% 综合手续费）；**有营业执照后**：直接签约微信支付/支付宝（0.6%） |
| iOS 付费 | **必须走 Apple IAP**，无替代方案；利用 Small Business Program 把佣金降到 12% |
| 定价 | Android/鸿蒙 ¥1/点；iOS **不要按 ¥1.5/点**，而是用「档位换算」（如 ¥3 = 2 点），原因见 §2.4 |
| 最大合规风险 | K12 学科类培训监管 + App 备案，详见 §6 |

## 1. 变现模型总览

```
用户获得点数                         点数消耗
├─ 注册赠送 1 点（一次性）             └─ 每次 AI 失分分析 = 1 点
├─ 看激励视频：10 次 = 1 点
└─ 充值
   ├─ Android / 鸿蒙：¥1.00 = 1 点
   └─ iOS：走 IAP，价格档位对齐 ≈¥1.50/点
```

**必须先算清楚的一笔账**：单次 AI 分析的模型成本 `c`。只有当

- 广告路径：`10 次广告收入 ≥ c`
- 充值路径：`点数售价 × (1 - 渠道费率 - 税) ≥ c`

两条都成立，这个商业模式才成立。`c` 的估算方法见 [03-AI分析链路](03-AI分析链路.md) 第 6 节。

## 2. 苹果 App Store（iOS 唯一合法路径）

### 2.1 佣金率【已核实】

苹果 2026 年 3 月 12 日官方公告：**自 2026 年 3 月 15 日起**，中国大陆 App Store 的手续费率调整如下：

| 类型 | 调整后 | 调整前 |
| --- | --- | --- |
| 标准 App 内购买 / App 内付费交易 | **25%** | 30% |
| App Store Small Business Program 与 Mini Apps Partner Program 的合格交易 | **12%** | 15% |
| 订阅满一年后的自动续订 | **12%** | 15% |

来源：[Apple Developer 官方公告](https://developer.apple.com/jp/news/?id=dadukodv)（
[中文报道](https://finance.sina.cn/2026-03-13/detail-inhqvamv4243549.d.html)）

**行动项**：注册 Apple Developer Program 后立即申请 **App Store Small Business Program**（年收入 ≤ 100 万美元即可），佣金从 25% 降到 **12%**——对个人开发者来说这是最值钱的一步。

### 2.2 个人开发者账号能否用 IAP？

**能。** Apple Developer Program 的 **个人（Individual）** 类型账号可以正常配置 App 内购买项目、接收 IAP 收入并结汇。限制只在于：开发者名称显示为个人姓名、不能做企业内部分发。年费 US$99【已核实为 Apple 公开定价，中国区具体金额以注册页为准】。

### 2.3 虚拟点数必须走 IAP 吗？

**是。** 按照 App Store 审核指南，App 内解锁的功能、虚拟货币、点数等数字内容**必须**使用 IAP，不得引导用户到 App 外（微信/支付宝/网页）购买，否则会被拒审，常见理由包括：

- 使用非 IAP 的支付方式销售虚拟商品
- App 内出现「去官网充值」「联系客服购买」等外部购买引导
- 未提供「恢复购买」功能

**注意**：这意味着**同一个 App 在 iOS 端必须隐藏微信/支付宝充值入口**。本项目 `account/index.vue` 已按平台区分套餐（`apple_iap` vs `wechat`），iOS 端不会展示第三方支付入口。

### 2.4 iOS 定价不能随便写 ¥1.50【重要】

App Store Connect 的 IAP 价格是**从苹果给定的价格点中选**，不是任意数字。中国区是否提供 ¥1.50 这个价格点 **【待确认】**（需在 App Store Connect 的价格下拉里实际查看）。

- **若 ¥1.5 可选**：直接按 1 点 = ¥1.5 上架。
- **若不可选**（更可能的情况）：不要做「¥1.5 = 1 点」，而是做**档位对齐**：

| IAP 商品 | 点数 | 折算单价 | 苹果抽 12% 后实收 |
| --- | --- | --- | --- |
| ¥3 | 2 点 | ¥1.50/点 | ¥2.64 |
| ¥6 | 4 点 | ¥1.50/点 | ¥5.28 |
| ¥18 | 12 点 | ¥1.50/点 | ¥15.84 |
| ¥50 | 33 点 | ¥1.52/点 | ¥44.00 |

> 关键点：**点数与商品是「多对多」关系**（1 个商品给 N 点），不要做「1 点 = 1 个商品」。这样既能绕开价格档位限制，也能让 iOS 与 Android 的每点收入接近。

### 2.5 定价数学验证

| 佣金率 | 用户付 ¥1.50 | 实收 | 相对 Android 的 ¥1.00 |
| --- | --- | --- | --- |
| 25%（标准） | 1.50 | **1.125** | +12.5% |
| 12%（Small Business） | 1.50 | **1.32** | +32% |
| （旧 30% 对照） | 1.50 | 1.05 | +5% |

结论：¥1.50/点 在 25% 佣金下仍比 ¥1.00 高 12.5%，**能覆盖苹果抽成**；申请 Small Business Program 后利润空间明显更好。若模型成本 `c` 逼近 ¥1.00，iOS 定价需上调到 ¥2.00/点 级别才安全。

## 3. 国内个人支付渠道（Android / 鸿蒙）

### 3.1 现实约束

微信支付（普通商户）与支付宝（APP 支付）**要求营业执照**（个体工商户或企业）。纯个人主体无法直接签约。两条路：

1. **办个体工商户**（推荐，长期正规）：线上即可办理，通常免费或几十元，需经营者身份证 + 经营场所（部分省份支持网络经营场所）。办下来后可正式签约微信支付/支付宝，费率约 **0.38%~0.6%**，资金直接清算，无第三方截留。
2. **第三方聚合支付**：**免营业执照**即可开通，但费率高、有跑路与合规风险。

### 3.2 第三方聚合支付对比

以下以**虎皮椒（xunhupay）**为例，其官方 FAQ 给出的信息【已核实，来源：[虎皮椒官方 FAQ](https://cps.xunhupay.com/faq.html)】：

| 项目 | 虎皮椒实际说法 |
| --- | --- |
| 是否需要营业执照 | **不需要**，无需公众号、无需微信支付商户号 |
| 开通材料（微信） | 正规网站地址、身份证、手机号、个人银行卡 |
| 开通材料（支付宝） | 已实名认证的支付宝账号（未被清退过） |
| 费率构成 | 开户费 + **平台交易费 1%~2%** + 微信/支付宝官方费率 **0.6%** |
| 综合成本 | 约 **1.6%~2.6%**（明显高于直签的 0.6%） |
| 资金流向 | 虎皮椒不碰资金：微信 D+1 清算到你的银行卡，支付宝 D0 到支付宝余额 |
| 审核 | 全人工，资料齐全时约 30 分钟 |
| 网站数量 | 最多 3 个，每个都要审核 |
| 明确禁入 | 色情、赌博、版权内容、付费入群、**发卡/易支付**、账号销售、虚拟币、VPN 等 |

**你必须注意的两点**：

1. 虎皮椒明确把「发卡、易支付」列为高风险禁入类型。你的业务是**学习工具 + 点数计费**，本身不在禁入列表，但**申请时填写的业务描述必须与实际一致**（官方会每天人工审核订单内容，不符会限额或关闭权限）。
2. 这类服务本质是「API 技术服务 + 借用你个人实名账号收款」，**一旦业务被判定违规，你的个人微信/支付宝账号可能受限**。因此这条路适合**验证期**，不适合长期依赖。

同类的其他服务商（PayJS、XorPay、GOGO 支付等）机制类似，**费率与资质要求请各自核实【待确认】**，选择时优先看：是否为正规注册公司、有没有增值电信业务经营许可证（如虎皮椒主体公示了「渝B2-20240653」）、是否承诺不碰资金、退款与纠纷处理流程。

### 3.3 安卓 / 鸿蒙渠道的额外抽成

| 分发渠道 | 虚拟支付要求 |
| --- | --- |
| 华为应用市场（HarmonyOS / Android） | **【待确认】** 游戏类通常强制走华为支付；工具/教育类应用内虚拟商品目前多可自建支付，但上架审核会核对支付合规性，务必以当期《华为应用市场审核指南》为准 |
| 小米 / OPPO / vivo / 应用宝 | 各自有联运与虚拟支付政策，**非游戏类工具应用一般允许第三方支付**，但需提供支付资质说明 |
| Google Play | 若**不上架** Google Play，则完全绕开其 15%~30% 抽成；国内用户基本用不到，建议 Android 只发国内商店 |

> 实操建议：鸿蒙与安卓首发**只上架国内应用市场 + 官网 APK**，不做海外分发，能把渠道抽成控制在 0（只有支付通道费）。

## 4. 激励视频广告

### 4.1 平台选择

| 平台 | 适配端 | 个人开发者 | 备注 |
| --- | --- | --- | --- |
| 穿山甲（CSJ / 巨量引擎） | Android、鸿蒙 | 支持（实名认证）**【待确认当前政策】** | 国内激励视频 eCPM 通常最高 |
| 优量汇（腾讯 GDT） | Android、鸿蒙 | 支持 | 可作为第二瀑布流 |
| 华为广告联盟 | HarmonyOS | 支持 | 鸿蒙原生适配最好 |
| AdMob | iOS | 支持 | iOS 端唯一顺畅的国内可用方案（Google 服务在国内 iOS 上可访问广告请求） |
| uni-ad（DCloud 聚合） | 全端 | 支持 | **推荐**：一套 `uni.createRewardedVideoAd` API 打全端，底层自动聚合穿山甲/优量汇/AdMob，省去分别接 SDK |

项目代码已按 uni-ad 的 API 写好（`account/index.vue` 的 `REWARDED_AD_PID`），申请到广告位 ID 后填入即可；留空时走演示流程。

### 4.2 「10 次广告 = 1 点数」到底亏不亏？

激励视频的单次展示收益 ≈ `eCPM / 1000`。国内激励视频 eCPM 常见区间约 **¥40 ~ ¥120**【经验区间，**待确认**，务必用你自己的后台实测】。

| eCPM | 10 次广告收入 | 对比 1 点数的价值（¥1.00） |
| --- | --- | --- |
| ¥40 | ¥0.40 | **亏**：若单次分析成本 > ¥0.40 就是亏损 |
| ¥60 | ¥0.60 | 勉强够 |
| ¥100 | ¥1.00 | 持平 |

**结论与建议**：

1. 10 次广告换 1 点是**偏慷慨**的设定，只有当单次 AI 分析成本稳定低于 ¥0.5 时才安全。
2. **先实测再定档**：上线后用 20 份真实试卷测出平均成本 `c`，然后按 `需要次数 = ceil(1.5 × c / 单次广告收益)` 反推，必要时改成「20 次广告 = 1 点」或「15 次广告 = 1 点」，这个数字放在后端配置 `ADS_PER_CREDIT` 里，随时可调，不用发版。
3. **广告有平台风控**：新账号初期 eCPM 通常偏低，且激励视频需要用户主动触发、有每日上限，不要把它当作主要收入来源。
4. 广告回调必须**服务端验签 + event_id 幂等**（本项目已实现幂等），否则会被刷。

## 5. 收款合规与资金安全

- 无论走哪条路，**收款主体、App 备案主体、隐私政策里的运营者名称三者必须一致**，否则应用商店审核会卡。
- 保留完整的**交易流水与退款记录**，至少 3 年。
- 页面必须提供**退款入口或客服联系方式**。
- 不要使用「充值返利」「拉人头返点」等模式，容易触及传销/赌博式运营的监管红线。
- 未成年人消费：需提供退款通道，并对大额充值做限制（见 §6）。

## 6. 必须知道的合规红线

| 事项 | 要求 | 对本项目的影响 |
| --- | --- | --- |
| **App 备案** | 工信部 App 备案，2023 年起强制 | 未备案无法在国内应用商店上架、苹果中国区也要求提供备案号。**这是第一优先级，周期约 1~4 周** |
| ICP 备案 | 域名 + 服务器在国内则必须 | 后端接口域名需要 |
| 公安联网备案 | ICP 通过后 30 日内 | — |
| **K12 学科类培训监管** | 「双减」政策对义务教育阶段学科类校外培训有严格限制（不得在节假日开展、不得资本化运作等） | **这是本项目最大的政策风险**。规避思路：定位为**学生自主使用的学习工具**，而不是「培训服务」——不提供课程、不排课、不承诺提分、不做教师授课、不做排名与社交对比、不向家长销售"提分服务" |
| 若涉及高中阶段 | 高中阶段学科类培训参照执行，各地口径不同，**建议咨询当地教育主管部门**【待确认】 | 你的示例数据用了高二，属于敏感区间，请务必确认当地口径 |
| 生成式 AI 服务 | 提供生成式 AI 功能可能涉及算法备案/安全评估 | **【待确认】**：调用已备案的第三方大模型（如通义千问）通常比自研模型合规压力小，但仍建议咨询合规服务商 |
| 个人信息保护 | 《个人信息保护法》+《未成年人个人信息网络保护规定》 | 手机号属于个人信息，需明示收集目的；若用户可能为未成年人，需**取得监护人同意**，并提供删除通道 |
| 数据安全 | 试卷与答题卡属于用户上传内容 | 加密存储、最小化留存、支持用户一键删除（本项目 `DELETE /exams/{id}` 支持级联删除） |

> **建议**：如果目标用户明确是义务教育阶段学生，请在正式投入前先做一次合规咨询。这个风险比技术风险更可能让项目直接停摆。

## 7. 分阶段落地路径

### 阶段一：验证期（0~3 个月，个人身份）

1. 后端 + 前端跑通，仅**内测分发**（TestFlight、APK 直装、鸿蒙内测），**先不上架应用商店**——这样可以暂时不做 App 备案，快速验证产品是否有价值
2. 变现只用**注册赠送 + 激励视频**（广告平台实名即可接入，无需营业执照）
3. 充值暂不开放，避免支付合规问题
4. 重点：测出「单次 AI 分析平均成本」和「用户完成一次分析后的留存」

### 阶段二：合规起步（3~6 个月）

1. 办理**个体工商户**（线上可办），签约微信支付 + 支付宝（0.6%），这是最干净的收款路径
2. 完成 ICP 备案 + App 备案 + 隐私政策 + 用户协议
3. 上架国内安卓市场（应用宝、小米、OPPO、vivo、华为/鸿蒙）
4. 开放充值：Android/鸿蒙 ¥1.00/点

### 阶段三：iOS 与规模化

1. 注册 Apple Developer Program（个人账号）→ 立即申请 **Small Business Program**（佣金 12%）
2. iOS 版**隐藏第三方支付入口**，只保留 IAP，用「¥3 = 2 点」这类档位对齐 ≈¥1.50/点
3. 上架 App Store（需提供 App 备案号）
4. 按实测成本重新校准 `ADS_PER_CREDIT` 与点数定价
