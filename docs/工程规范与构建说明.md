# 工程规范与构建说明

本文档由 M1 里程碑建立，记录工程骨架的构建约定。后续里程碑不得修改本章列出的版本与结构，
确需变更时须在 CHANGELOG 记录原因，并同步更新本文件。

## 1. 环境要求

| 项目 | 版本 | 说明 |
| --- | --- | --- |
| JDK | 17 | 编译目标与 Gradle 运行环境均为 17；更高 JDK 亦可运行 Gradle，但 jvmTarget 固定为 17 |
| Gradle | 8.7 | 由 gradle/wrapper/gradle-wrapper.properties 固定 |
| AGP | 8.5.2 | 见 gradle/libs.versions.toml |
| Kotlin | 1.9.24 | 与 Compose Compiler 1.5.14 配套 |
| Android SDK | compileSdk 34 / build-tools 34.0.0 | minSdk 24，targetSdk 34 |

## 2. 首次构建

1. 复制 local.properties.example 为 local.properties，填写本机 sdk.dir。
2. 执行 ./gradlew :app:assembleDebug。
3. 产物位于 app/build/outputs/apk/debug/app-debug.apk。

local.properties、签名文件与密钥一律不提交，.gitignore 已排除。

## 3. 版本目录规则

- 全部依赖版本集中在 gradle/libs.versions.toml，模块脚本内禁止出现硬编码版本号。
- 本文件由 M1 一次性列全，覆盖 M1-M8 全部里程碑所需依赖。
- 新增依赖时：先在 [versions] 增加版本键，再加 [libraries] 别名，最后在 app/build.gradle.kts 引用。

## 4. 模块结构

单模块 app，包名 com.totop.app，按《AI 辅助学习 App 开发方案》2.3 节组织：

    com/totop/app/
      App.kt                  Hilt 应用入口
      MainActivity.kt         唯一 Activity，UI 全部 Compose
      navigation/             路由常量、底部导航、导航宿主
      ui/                     Compose 页面，页面一律以 Screen 结尾
        theme/                色彩、排版、主题
        components/           可复用组件
        solve/ mistakes/ knowledge/ report/ settings/   功能页面
      domain/                 model 与 algorithm（纯 Kotlin，可单测）
      data/                   local(Room) / remote(LLM) / repo / prefs
      ml/                     OCR、图片预处理、模型路由、TTS
      work/                   WorkManager 任务
      util/                   导出、备份、公式渲染等工具

## 5. 导航路由

| 路由 | 页面 | 层级 | 进入方式 |
| --- | --- | --- | --- |
| solve | SolveScreen | 顶层 | 启动页与底部栏 |
| mistakes | MistakesScreen | 顶层 | 底部栏 |
| knowledge | KnowledgeScreen | 顶层 | 底部栏 |
| report | ReportScreen | 顶层 | 底部栏 |
| settings | SettingsScreen | 顶层 | 底部栏 |
| kpoint_detail/{kpointId} | KnowledgePointDetailScreen | 二级 | 知识点处点击 |
| review | ReviewScreen | 二级 | 错题本进入复习 |
| backup | BackupScreen | 二级 | 设置进入备份 |

参数约定：因 minSdk 24，不使用路由级对象序列化，统一走字符串路径参数；
kpointId 必须是内置知识点树的受控 ID（例如 KP_MATH_0312），AI 不得自造。

## 6. 性能与合规约定

- 不使用毛玻璃（高斯模糊）、视差、大面积弹性动画；底部栏不做出现动画。
- 不启用动态取色，主题固定，保证各机型一致且零额外计算。
- 不使用 XML View，不引入统计、广告、埋点 SDK。
- 代码与文档禁止使用 emoji。
- 页面离开必须取消网络请求（M2 起），所有 AI 调用须写 ai_trace。

## 7. 打包与包体

- 仅打包 arm64-v8a（abiFilters），首次安装包体积已按 30MB 门禁控制。
- release 开启 R8 与资源压缩，ProGuard 规则保留 kotlinx.serialization、Retrofit、Hilt、Room、ML Kit 契约。
- 已配置 Baseline Profile 依赖（androidx.profileinstaller），M8 生成实际 profile 文件。
- 网络默认仅允许 HTTPS；明文仅为 localhost、127.0.0.1、10.0.2.2 放行，用于本地 Ollama 端点。

## 8. Kotlin 编译策略

gradle.properties 中固定 kotlin.compiler.execution.strategy=in-process。
原因：部分受限环境与 CI 沙箱无法建立 Kotlin 编译守护进程的本地连接，进程内编译可稳定完成构建。
若本机编译速度受影响，可在个人环境覆盖该值，但不得提交修改。

## 9. CI

- .github/workflows/ci.yml：PR 触发，执行 gitleaks、lint、单元测试与 assembleDebug。
- .github/workflows/release.yml：打 tag 触发，写入密钥后构建 release APK 并校验 30MB 体积门禁，上传到 Release 附件。
